## ✅ 免费接口（每月 50,000 次）

| 接口类型 | API 路径 | 说明 |
|----------|----------|------|

## 🔧 配置

### 步骤 1：获取 API Key 和 API Host

1. 访问 [和风天气开发者平台](https://dev.qweather.com/)
2. 注册/登录账号
3. 进入「项目管理」→ 选择你的项目
4. 复制 API Key 和 **API Host**

### 步骤 2：配置 .env 文件

```bash
# .env
QWEATHER_API_KEY=你的 32 位 API_Key
QWEATHER_API_HOST=你的项目 Host（从控制台获取）
```

### 步骤 3：监控用量

1. 定期查看项目后台用量统计
2. 设置用量告警（80%、90%、100%）
3. 根据用量调整查询频率

---

## 💡 建议

1. **监控用量**：定期查看项目后台用量统计

## ❓ 常见问题

### Q: 如何避免超出免费额度？

1. 设置用量告警（80%、90%、100%）
2. 缓存查询结果（城市 ID、天气数据）
3. 降低查询频率
4. 合并批量查询

### Q: 免费额度和付费额度的区别？

- **免费额度**：每月 50,000 次，仅限常规接口（天气/空气/天文等）
- **付费额度**：超出免费额度后按阶梯计费，或台风接口（无免费）

### Q: 如何查看当前用量？

访问 [项目控制台](https://dev.qweather.com/console/project) 查看实时用量统计

### Q: 台风接口为什么收费？

台风数据需要特殊的数值预报模式和专家分析，数据成本较高，因此单独计费
